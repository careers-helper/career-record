# Conference Speaking

## Overview
Records Elena's conference talks and public presentations. These are used to strengthen CVs where public communication, thought leadership, or community involvement is valued.

## Talks

### "The Strangler Fig in Practice: Migrating 15 Angular Apps to React Without a Feature Freeze"
- **Event:** React Summit, Amsterdam — November 2025
- **Format:** 25-minute talk + Q&A
- **Summary:** Case study of the Aegon UK migration. Covered the strangler fig pattern, Web Components interop layer, migration sprints, and lessons learned from scaling across 8 teams. ~300 attendees. Recording published on YouTube.
- **Skills demonstrated:** Frontend architecture, migration strategy, public speaking, enterprise engineering
- **Relates to:** Aegon UK roles (2022–present)
- **When to surface:** Roles that value conference speaking, community involvement, or migration expertise

### "Codemods at Scale: Automating the Boring Parts of Framework Migration"
- **Event:** Frontend Connect, London — June 2024
- **Format:** 20-minute talk
- **Summary:** Practical walkthrough of building and deploying jscodeshift-based codemods for Angular-to-React migration. Included live demo of react-migrator CLI. ~150 attendees.
- **Skills demonstrated:** Developer tooling, AST manipulation, open-source development
- **Relates to:** Aegon UK roles, react-migrator personal project
- **When to surface:** Roles involving developer tooling, migration, or open-source contribution

### "Accessibility Is Not a Feature: Lessons from Government Digital Services"
- **Event:** London Web Standards meetup — March 2019
- **Format:** Lightning talk (10 minutes)
- **Summary:** Reflections on working at GDS and how progressive enhancement and accessibility-first thinking changed Elena's approach to frontend development. Informal meetup setting, ~60 attendees. Not recorded.
- **Skills demonstrated:** Accessibility, progressive enhancement, public speaking
- **Relates to:** GDS role (2016–2018)
- **When to surface:** Roles where accessibility expertise is important
