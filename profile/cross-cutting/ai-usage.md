# AI Usage

## Snapshot
Records Elena's adoption and use of AI-assisted development tools across work and personal contexts. This file exists to provide accurate, specific claims about AI experience when roles ask for it, and to avoid over-stating or under-stating familiarity.

## Timeline

### 2024–present: Active daily use
- **GitHub Copilot** (Aegon UK, approved for use from Q2 2024): Used daily for code completion, test generation, and boilerplate. Most effective for repetitive migration patterns and test scaffolding. Elena estimates it saves 30–60 minutes per day on routine tasks.
- **Claude** (personal, via Claude Pro subscription from mid-2024): Used for code review, architectural brainstorming, drafting documentation, and exploring unfamiliar APIs. Primary tool for non-code writing tasks.
- **ChatGPT** (personal, free tier initially, Plus from late 2023): Used earlier than Claude. Gradually replaced by Claude for most tasks by mid-2024.

### 2023: Early adoption
- **GitHub Copilot** (personal): Started using on react-migrator project. Found it particularly useful for writing jscodeshift transform boilerplate.
- **ChatGPT** (personal): Used for learning, rubber-ducking architectural decisions, and drafting conference talk outlines.

### Pre-2023: No meaningful AI tool usage
- Aware of Tabnine and Kite but did not adopt them.

## Tools and access constraints
- At Aegon UK: GitHub Copilot is approved. ChatGPT and Claude are not approved for use with proprietary code. Elena uses them only for general questions and personal projects.
- Personal: Claude Pro, GitHub Copilot (individual plan)

## Validation and review approach
Elena treats AI-generated code as a first draft. All generated code is reviewed, tested, and understood before committing. She does not use AI for code she cannot verify through her own expertise.

## Notes on scope
AI usage is supplementary to Elena's workflow, not central to her professional identity. It should be mentioned when roles specifically ask about AI experience but should not be overstated.
