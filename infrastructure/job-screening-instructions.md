# Job Screening Instructions

> **Purpose:** Rubric and output format for AI-assisted job screening. Personal preferences, hard requirements, and experience profile are in `profile/job-preferences.md` — read that file before applying this rubric.

---

## 1. Screening Rubric

Evaluate each job description against these dimensions. For all thresholds, dealbreakers, and preference weights, refer to `profile/job-preferences.md`. Flag mismatches and unknowns.

### Location & Arrangement
- Remote, hybrid, or in-office? If hybrid: location and number of days?
- UK timezone? GBP/UK PAYE for remote roles?
- Relocation required?

### Compensation
- Base salary disclosed?
- Pension contribution included?
- Equity: RSUs (public company) or stock options (pre-IPO)?
- Bonus structure?

### Seniority & Role Type
- Seniority level (Staff / Principal / Senior Staff)?
- IC vs management? Line reports?
- Tech leadership vs strategic leadership?

### Industry & Domain
- What industry? Note against excluded industries in `profile/job-preferences.md`.
- What domain — frontend architecture, platform engineering, migration, feature delivery?

### Technology
- Primary tech stack?
- Long-term tech direction?
- Migration or modernisation involved?
- Greenfield vs existing codebase?

### Culture & Work Style
- Work-life balance signals?
- Meeting load?
- Autonomy level?
- Team structure: cross-cutting platform role vs embedded in a single product team?

---

## 2. Experience Matching

Consult `profile/job-preferences.md` > "Profile Summary for Screening" to understand which roles and projects to draw from, what to emphasise, and acknowledged gaps. Then apply that context to the dimensions above when producing the fit assessment.

Source files for evidence:
- `profile/work-experience/` — employment history
- `profile/personal-projects/` — personal projects
- `profile/cross-cutting/` — conference speaking, AI usage, mentoring

---

## 3. Output Format

Produce a structured fit assessment as `output/<role-folder>/suitability.md` with these sections:

### Overall
- **Fit score:** Strong fit / Good fit / Cautious fit / Poor fit
- **Recommendation:** Pursue / Cautious / Skip
- **One-line summary:** Why this recommendation

### Key Alignments
Bullet list of what matches well (role, tech, domain, arrangement, etc.)

### Key Concerns
Bullet list of mismatches, unknowns, or red flags

### Experience Highlights
What to emphasise if applying — specific roles or projects that demonstrate fit

### Questions to Ask
Information gaps that would change the assessment (e.g. meeting load, team structure, salary range)

### Compensation Note
If salary/comp not disclosed: flag this, note the hard requirements from `profile/job-preferences.md`, and recommend asking early.
